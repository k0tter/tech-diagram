# リファレンスアーキテクチャ図(AWS 公式一頁物の型)

「リファレンスアーキテクチャ」「番号付きで解説」と頼まれたら 1 回 Read する。
ワークフロー・meta/legend・検証は SKILL.md と同一。

## 番号バッジとステップ説明

- **番号はノードに振る** — 流れ順(起点=リクエスト側が 1)の各サービスノードに
  `"step": N`(1〜99 の連番・図内一意)。バッジ(濃紺丸+白数字)はアイコン
  右上角に自動配置される
- バッジ配色はトップレベル `"badge_style"` で選ぶ。既定 `"dark"`=濃紺+白数字
  (公式リファレンスアーキテクチャ一頁物 PDF の実例準拠)。`"light"`=白地+黒太字
  +濃紺ストローク(AWS Architecture Icons デッキ 2025-07-31 slide 13
  "Numbered Callouts" 準拠)。公式内でも流儀が割れているためオプション化している
- トップレベル `"steps": ["説明1", ...]` に**バッジと同数**の説明(各 1〜3 文)を
  書くと、図の右側に薄グレーの説明パネル、`name` が左上の大タイトルとして
  描画される(公式一頁物のレイアウト)
- **矢印にはテキストラベルを書かない**(公式の実運用は無地の直交線。意味は
  番号+説明パネル側に載せる)。ノードラベルは「サービス名\n役割」の 2 行
- エッジへの `step` も可(Guidance 系の変種)だが、手動配線(exit/entry 直書き)
  エッジには自動配置できない(WARN が出る。番号はノードへ)
- 欠番・重複・説明との不一致は WARN/W12 が検出する
